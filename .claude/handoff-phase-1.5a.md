# Hand-off — Phase 1.5a (Playwright Scaffolding)

Playwright is wired into `apps/silbe/` with `playwright.config.ts` (chromium-only, desktop 1280×800 + mobile 393×852 projects, auto-starting `pnpm dev` as webServer), four specs in `tests/e2e/layout.spec.ts` covering the §1.4 acceptance contract (homepage visual snapshot for both viewports, mobile drawer focus-trap + ESC + overlay-close interactions, footer-link route assertions, and 308-redirect verification for the five Phase-0 redirect rules), with snapshot baselines committed (8 passing / 2 skipped on desktop project where the drawer surface is intentionally hidden). Lighthouse CI is wired separately via `lighthouserc.json` + `pnpm test:lighthouse` against `pnpm start` so it can run locally or in a future CI stage with a real built bundle. The `lighthouse-ci` package was swapped for `@lhci/cli` (the Google-canonical tool that exposes the `lhci` binary the MEGAPROMPT spec expects). CI runs on every PR and push to main via `.github/workflows/test.yml` — install, content-lint, build, Playwright. Lighthouse is excluded from CI for now because it needs a deploy URL or a longer-running server; revisit when Phase 2 lands a stable preview to assert against. Side-effect from this scaffold: `Wordmark` got a small API simplification (now takes `height` only and derives width from intrinsic aspect 1027:302 to silence Next/Image's aspect-ratio warning), and the repo-root `node_modules` was reinstalled because the virtual store still pointed at the old `C:\Users\Merlin\…` path from before the profile cleanup.
